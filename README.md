# Sustainable Fashion Trends – Exploratory Data Analysis

## 📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the **Sustainable Fashion Trends – 2024** dataset.  
The goal is to analyze sustainability practices, environmental impact metrics, pricing strategies, and market performance of fashion brands using data-driven insights.

## 📂 Dataset Information
- **Dataset Name:** Sustainable Fashion Trends – 2024  
- **Domain:** Fashion Industry & Sustainability  
- **Total Records:** 5,000  
- **Total Columns:** 15  

### 🔹 Data Types
- **Categorical Variables:** Brand details, sustainability indicators, market trends  
- **Numerical Variables:** Environmental impact metrics, pricing data  

---

## 📑 Column Description
| Column Name | Description |
|-----------|------------|
| Brand ID | Unique brand identifier |
| Brand Name | Name of the fashion brand |
| Country | Operating country |
| Sustainability Rating | Low / Medium / High |
| Material Type | Primary material used |
| Eco-Friendly Manufacturing | Yes / No |
| Recycling Programs | Recycling initiatives |
| Certifications | Sustainability certifications |
| Carbon Footprint | Emissions (metric tons) |
| Water Usage | Water consumption (liters) |
| Waste Production | Waste generated (kg) |
| Product Lines | Number of product categories |
| Average Price | Mean product price (USD) |
| Market Trend | Growing / Stable / Declining |

## 📊 Exploratory Data Analysis (EDA)

### 🔹 Univariate Analysis
- Analyzed distribution of average product prices  
- Identified budget, mid-range, and premium brands  

### 🔹 Bivariate Analysis
- Sustainability rating vs average price  
- Recycling programs vs market trends  
- Carbon footprint vs water usage  

### 🔹 Multivariate Analysis
- Examined relationships between environmental metrics and pricing  
- Observed limited strong correlations among variables  

---

## 🧾 Key Insights
- Sustainable practices significantly reduce environmental impact  
- Brands with higher sustainability ratings show better market performance  
- Consumers accept slightly higher prices for sustainable products  
- Sustainability provides both environmental and business value  

---

## 🏁 Conclusion
The EDA revealed valuable insights into sustainable fashion practices.  
The analysis shows that sustainability metrics often function independently of pricing but positively influence market trends.  
This project demonstrates the importance of data-driven decision-making in promoting sustainable fashion.
